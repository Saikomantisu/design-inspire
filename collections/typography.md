# Typography

Font libraries and tools for choosing typefaces and pairings.

[Back to the collection](../README.md)

## [Fontjoy](https://fontjoy.com/)

A font pairing generator that uses a neural network to suggest fonts that work together. Lock fonts you want to keep, generate new matches for the rest, and preview them with your own text.

- **Tags:** typography, font-pairing, tools

## [Fontshare](https://www.fontshare.com/)

A free font library from Indian Type Foundry, with typefaces you can download or load on the web. Each font's license covers its own permitted uses.

- **Tags:** typography, fonts, free
