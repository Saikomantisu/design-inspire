# Icons

Icon libraries and tools for finding and using icons in projects.

[Back to the collection](../README.md)

## [Iconify](https://iconify.design/)

An open source framework that brings popular icon sets together, with an icon browser, developer libraries, and an API. Each icon set has its own license, so check it before use.

- **Tags:** icons, svg, open-source, developer-tools

## [Lordicon](https://lordicon.com/)

A library of animated icons that you can customize and export in formats such as Lottie, SVG, GIF, and MP4. Free icons require attribution; see its [licenses page](https://lordicon.com/licenses) for what paid plans add.

- **Tags:** icons, animation, lottie

## [Pikaicons](https://pikaicons.com/)

A library of hand-drawn SVG icons in five styles: stroke, solid, duo-stroke, duo-solid, and contrast. Use them from a Figma file, or search the web app and copy icons as SVG or React, Vue, Svelte, React Native, or Solid code. A free pack covers personal and commercial use, and a one-time purchase unlocks the full library.

- **Tags:** icons, svg, figma, react, vue, svelte
